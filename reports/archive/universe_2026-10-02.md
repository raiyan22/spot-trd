# Small-universe study (2026-10-02)

Same v2 rules and parameters on every asset (nothing tuned per coin), one shared account, assets served in the fixed order BTC, ETH, SOL, ADA, LTC. Per-asset Binance minimum order and lot size are applied. Edge test = 100,000 USDT at 2% risk (so Binance's minimum doesn't bind); dollar columns use the real risk schedule. Base fills unless marked harsh.

**Total risk is held constant.** The single-asset per-trade risk budget (2% of equity below 50 USDT, else 1%) is the budget for the WHOLE account. `equal`: each of the k position slots gets 1/k of it. `heat`: a new position gets whatever budget the open positions' stops have not already used. More assets therefore never mean more total risk at the moment of entry.

Data starts (features available): BTC 2018-03-04, ETH 2018-03-04, SOL 2021-02-26, ADA 2018-11-02, LTC 2018-06-30. All universes are compared on the common window starting 2021-02-26 so they see the same market.

**Pre-registered materiality test** (fixed before any portfolio result was seen). A universe materially improves on BTC-only only if ALL hold, vs BTC-only on the same window with the same fills:

- M1 opportunity: trades per year at least 1.5x BTC-only
- M2 dollar return: edge-test annualized return at least 1.25x BTC-only, and still positive under harsh fills
- M3 risk: max drawdown no more than 25% deeper than BTC-only, and longest losing streak no more than 2 trades longer
- M4 consistency: annualized return no worse than BTC-only in BOTH halves of the window

## Which universes pass all four tests?

**No universe passes all four tests.** BTC-only stays the reference.

Configurations passing M2 (the dollar-return test): 0 of 18. The M3 streak clause penalises any universe that simply trades more often (more trades means longer streaks in trade counts); it is kept as pre-registered, but the conclusion does not depend on it, because M2 already fails everywhere.

BTC-only reference on this window: 6.3 trades/yr, CAGR +2.5%, max DD -12.7%, avg R +0.35, harsh CAGR +1.4%.
